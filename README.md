# D-word

A simple Danish vocabulary trainer that runs in the browser.

## Features

- Around 4,000 Danish words with English meanings
- An example sentence with English translation for every word
- Flashcards with spaced repetition
- True/false test mode
- Timed 20-word quiz
- Danish → English and English → Danish
- Search across words, meanings and examples
- Favorites and review lists
- Pronunciation using the browser's built-in speech
- Light and dark mode
- Works on desktop and mobile

## Usage

Open the site and start studying. No account or installation is needed.

Progress is saved in your own browser on your device.

## Privacy

No personal data is collected.
